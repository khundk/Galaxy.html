# YSA Shopify Theme — GitHub Branch

This branch is configured for **Shopify → Connect from GitHub**.

Theme files are at the **root** of this branch (required by Shopify).

## Connect in Shopify

1. **Online Store → Themes → Add theme → Connect from GitHub**
2. Repository: **khundk/Galaxy.html**
3. Branch: **`shopify-theme`** ← use this branch, NOT main
4. Click **Connect**

## Other branches

- `main` / `cursor/ysa-shopify-store-52d4` — source code + HTML paste files (not valid for GitHub theme connect)
- `shopify-theme` — valid theme at repo root for GitHub connect

## ZIP upload alternative

Download `ysa-shopify-theme.zip` from the other branch if GitHub connect doesn't work.
